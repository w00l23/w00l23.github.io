# w00l23.github.io

The home page of Mina Systems. One plain HTML file, no frameworks.

The background is a spiral galaxy and a field of stars drawn once on a 2D
canvas when the page loads or the window changes size: no images, no per-frame
work, and scrolling only slides the canvas a little. It is seeded, so it looks
the same on every visit.

`assets/` holds the card previews and the Iluminara screenshots.
